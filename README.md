# CMSC22 Laboratory Activity 8

## Introduction

As programmers, one of the fundamental skills we must develop is the ability to design and write good code. This requires more than making a program work, it also involves writing code that is understandable, maintainable, reusable, and appropriately structured.

To improve our programming skills, we must learn to recognize both good and bad code. By analyzing existing programs, we can identify effective design decisions, recognize potential problems, and propose solutions that improve code quality.
